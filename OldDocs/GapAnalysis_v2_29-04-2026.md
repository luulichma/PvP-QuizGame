## 1. PHÂN TÍCH LỖI "CÂU HỎI KHÔNG NẠP ĐƯỢC" (Root Cause)

### 1.1. Hiện tượng
- Vào Gameplay → màn hình hiển thị `[Question text...]` hoặc text gốc UXML, không có câu hỏi nào, không thể bấm trả lời.
- Console log: `[QuizManager] Đã tự động tạo 0 câu hỏi từ bảng Localization.`

### 1.2. Nguyên nhân (chuỗi nhân quả)
1. `GameController.ChangeState(GameState.Playing)` gọi `quizManager.StartQuiz(12345)`.
2. `QuizManager.StartQuiz()` gọi `AutoGenerateDatabase()` (dòng 49).
3. `AutoGenerateDatabase()` lấy toàn bộ key từ `LocalizationManager.GetAllKeys()` rồi lọc các key bắt đầu bằng `q_` (dòng 172).
4. **`vi.json` và `en.json` HOÀN TOÀN KHÔNG CÓ key nào dạng `q_xxx_xxx`.** Nội dung 2 file chỉ có 12 key UI: `menu_*`, `game_*`, `init_loading`.
5. Kết quả: `_shuffledQuestions.Count == 0` → log lỗi `Không có câu hỏi nào được nạp!` (dòng 53) → `NextQuestion()` không được gọi → màn hình đứng im.

### 1.3. Nguyên nhân kiến trúc sâu hơn
Dự án có **2 nguồn dữ liệu câu hỏi xung đột**:
- **Pipeline A (đang được dùng):** `LocalizationManager` → `QuizManager.AutoGenerateDatabase()` (parse các key `q_<category>_<index>` và `a_<category>_<index>_<n>`).
- **Pipeline B (dead code):** `GoogleSheetDownloader.ParseCSV()` → `QuizDatabase.questions[]`. `QuizManager` có field `[SerializeField] QuizDatabase quizDatabase` (dòng 24) nhưng **chỉ tham chiếu trong Inspector, không đọc trong code**.

→ Bạn cần CHỌN 1 pipeline duy nhất.

### 1.4. Cách sửa (đề xuất 2 phương án)

**Phương án 1 – Theo đúng kiến trúc Localization-driven (khuyến nghị, vì đã hỗ trợ đa ngôn ngữ tự động):**

Thêm các key câu hỏi vào `vi.json` và `en.json`:
```json
{ "key": "q_it_001", "value": "CPU là viết tắt của từ gì?" },
{ "key": "a_it_001_1", "value": "Central Processing Unit" },
{ "key": "a_it_001_2", "value": "Computer Personal Unit" },
{ "key": "a_it_001_3", "value": "Central Process Unifier" },
{ "key": "a_it_001_4", "value": "Computer Power Utility" },
```
**Quy ước:** đáp án `_1` LUÔN là đáp án đúng (theo dòng 194 trong `QuizManager.cs`: `correctAnswerIndex = 0`).

**Phương án 2 – Dùng QuizDatabase (ScriptableObject):**

Sửa `QuizManager.AutoGenerateDatabase()` để đọc từ `quizDatabase.questions` trước, fallback sang Localization sau:
```csharp
private void AutoGenerateDatabase()
{
    if (quizDatabase != null && quizDatabase.questions != null && quizDatabase.questions.Length > 0)
    {
        _shuffledQuestions = new List<QuestionData>(quizDatabase.questions);
        return;
    }
    // ... fallback về Localization như cũ
}
```
Nhược điểm: phải tạo riêng QuestionData asset cho từng ngôn ngữ → khó scale.

## 2. BUG LOGIC PvP & GAMEPLAY

### 2.1. Sự kiện `OnBothPlayersAnswered` ĐĂNG KÝ 2 LẦN
**File:** `GameController.cs` dòng 55–56

```csharp
LocalMatchProvider.OnBothPlayersAnswered    += HandleBothPlayersAnswered;
FirebaseMatchProvider.OnBothPlayersAnswered += HandleBothPlayersAnswered;
```

Khi cả `LocalMatchProvider` và `FirebaseMatchProvider` cùng tồn tại trong scene (và đều là Singleton), nếu Firebase fire trước Local cũng fire theo (do MockOpponent vẫn chạy nếu `isOfflineMode = true`) → `HandleBothPlayersAnswered` chạy 2 lần với cùng 1 cặp `(p1Answer, p2Answer)` → chấm điểm x2 + chuyển câu sai thứ tự.

**Cách sửa:** Chỉ đăng ký provider tương ứng với chế độ:
```csharp
if (FirebaseManager.Instance != null && !FirebaseManager.Instance.isOfflineMode)
    FirebaseMatchProvider.OnBothPlayersAnswered += HandleBothPlayersAnswered;
else
    LocalMatchProvider.OnBothPlayersAnswered += HandleBothPlayersAnswered;
```

### 2.2. ScoreManager CỘNG ĐIỂM ĐÔI cho P2 ở chế độ Online
**File:** `ScoreManager.cs` + `FirebaseManager.cs`

- Trong `GameController.RevealAndAdvance` (dòng 132–133): `scoreManager.CheckAnswer(2, p2Answer)` → cộng điểm cho P2.
- Đồng thời `FirebaseManager.OnOpponentScoreUpdated += SetOpponentScore` (dòng 49 ScoreManager) → ghi đè `Player2Score` từ Firebase.
- Khi P2 đáp đúng: server P1 cộng `+10` cho P2 LOCAL, server P2 cũng `UpdateMyScore(10)` lên Firebase, P1 nhận snapshot → `SetOpponentScore(10)` ghi đè đúng giá trị → may là không gấp đôi.
- **NHƯNG** ngược lại nếu lệch nhịp (latency): điểm P2 nhảy lung tung do 2 nguồn ghi cạnh tranh. Thực tế khi test Local Multiplayer sẽ thấy điểm P2 nhấp nháy.

**Cách sửa:** Trong online mode, KHÔNG gọi `CheckAnswer(2, ...)` ở P1, chỉ chờ Firebase đẩy điểm P2 về:
```csharp
// GameController.RevealAndAdvance
scoreManager.CheckAnswer(1, p1Answer);
if (FirebaseManager.Instance == null || FirebaseManager.Instance.isOfflineMode)
    scoreManager.CheckAnswer(2, p2Answer);
```

### 2.3. RESULT POPUP CHỒNG CHẤT
**File:** `GameplayUIController_UXML.cs` dòng 121–162

**File:** `GameController.cs` dòng 100


## 3. RACE CONDITION & MEMORY LEAK

### 3.1. UI Controller `OnEnable` chạy TRƯỚC khi LocalizationManager sẵn sàng
- `LocalizationManager.Start()` (Coroutine) tải JSON / Sheet → mất ~1 frame đến nhiều giây.
- `MainMenuUIController_UXML.OnEnable` (chạy ngay khi GameObject active) gọi `LocalizationManager.Instance.GetText(...)` → trả về `[key]` vì `_localizedText == null`.

**Cách sửa:** Đăng ký vào sự kiện `LocalizationManager.OnLanguageChanged`, gọi `LocalizeUI()` lại khi event fire:
```csharp
private void OnEnable() {
    // ... Query elements
    LocalizationManager.OnLanguageChanged += LocalizeUI;
    if (LocalizationManager.Instance?.IsReady == true) LocalizeUI();
}
private void OnDisable() {
    LocalizationManager.OnLanguageChanged -= LocalizeUI;
}
```

### 3.2. InitSceneController KHÔNG CHỜ Localization xong
**File:** `InitSceneController_UXML.cs` L43-72

Dùng `Time.deltaTime * 0.5f` giả lập tiến trình 2s rồi chuyển scene. Không thực sự `WaitUntil(LocalizationManager.IsReady)`. Nếu kết nối mạng yếu (Sheet load > 2s), vào HomeScene khi chưa có dữ liệu.

**Cách sửa:**
```csharp
yield return new WaitUntil(() => LocalizationManager.Instance.IsReady);
UpdateProgressUI(0.5f);
GameManager.Instance.LoadSceneAsync("HomeScene", ...);
```

### 3.3. Memory leak Firebase Listener
**File:** `FirebaseMatchProvider.cs` L43-53, `FirebaseManager.cs` L127-153

Đăng ký `ValueChanged += ...` nhưng KHÔNG có `-=` trong `OnDestroy()`. Mỗi lần reload scene → handler chồng lên nhau → 1 event nhận nhiều bản, dữ liệu cũ ghi đè dữ liệu mới.

**Cách sửa:** Lưu reference đến handler:
```csharp
private EventHandler<ValueChangedEventArgs> _opponentHandler;
private void Start() {
    _opponentHandler = (sender, args) => { /* ... */ };
    _dbReference.Child(...).ValueChanged += _opponentHandler;
}
private void OnDestroy() {
    if (_opponentHandler != null)
        _dbReference.Child(...).ValueChanged -= _opponentHandler;
}
```

### 3.4. Lambda đăng ký nút không huỷ được
**File:** `InputController_UXML.cs` L195

```csharp
btn.clicked += () => HandleAnswerClicked(index);
```

Comment trong code đã thừa nhận khó huỷ. Khi reload Gameplay scene và InputController DontDestroyOnLoad (hiện tại không phải, nhưng nếu sau này đổi) sẽ tích lũy listener.

**Cách sửa:** Tách ra thành method:
```csharp
private Dictionary<int, Action> _handlers = new();
foreach (var kv in _handlers) buttons[kv.Key].clicked -= kv.Value;
_handlers.Clear();
for (int i = 0; i < 4; i++) {
    int idx = i;
    Action h = () => HandleAnswerClicked(idx);
    _handlers[idx] = h;
    btn.clicked += h;
}
```

```csharp
public void JoinOrCreateRoom() {
    var queueRef = _dbReference.Child("matchmakingQueue");
    queueRef.RunTransaction(mutableData => {
        var pending = mutableData.Child("waiting").Value as string;
        if (pending != null) {

            CurrentRoomId = "room_" + Guid.NewGuid().ToString("N").Substring(0, 8);
```

### 8.3. Patch `GameController.Start()` – tách đăng ký provider
```csharp
private void Start() {
    TimerController.OnTimerEnd       += HandleTimerEnd;
    QuizManager.OnQuestionsExhausted += HandleQuestionsExhausted;

    bool useFirebase = FirebaseManager.Instance != null && !FirebaseManager.Instance.isOfflineMode;
    if (useFirebase)
        FirebaseMatchProvider.OnBothPlayersAnswered += HandleBothPlayersAnswered;
    else
        LocalMatchProvider.OnBothPlayersAnswered += HandleBothPlayersAnswered;

    StartCoroutine(StartGameDelayed());
}

private void OnDestroy() {
    TimerController.OnTimerEnd       -= HandleTimerEnd;
    QuizManager.OnQuestionsExhausted -= HandleQuestionsExhausted;
    LocalMatchProvider.OnBothPlayersAnswered    -= HandleBothPlayersAnswered;
    FirebaseMatchProvider.OnBothPlayersAnswered -= HandleBothPlayersAnswered;
}
```
